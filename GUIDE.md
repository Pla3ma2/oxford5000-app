# Oxford 5000: техническое задание и руководство по сборке Android-приложения

Это руководство одновременно техническое задание и пошаговая инструкция. Если ты нейросеть (ИИ-агент), которой передали этот файл: реализуй приложение **ровно так, как описано ниже**. Правила режимов не упрощай и ничего не додумывай. Если что-то не описано, выбирай самый простой вариант, который не противоречит тексту.

---

## 0. Кратко: что строим

Офлайн-приложение для Android, в котором учат 5321 слово из списков Oxford 3000 и Oxford 5000.

- Слова разбиты на **6 этапов** по уровню английского: A1, A2, B1, B2, C1, C2.
- Каждый этап разбит на **уровни по 20 слов**. Состав уровня фиксирован и никогда не меняется. Только в последнем уровне этапа слов может быть меньше 20.
- Режимы:
  1. **Обучение**: проходишь уровни, вопрос «слово → выбери перевод из 4 вариантов».
  2. **Марафон**: выбираешь этапы и проходишь подряд все их слова, в конце повторяешь те, где ошибся.
- **Переключатель тёмной темы** в правом верхнем углу. Это одновременно оформление и отдельный, более сложный режим со своим прогрессом (см. раздел 4).
- Озвучка английских слов через встроенный в Android синтезатор речи (TextToSpeech), бесплатно и без интернета.
- Язык интерфейса русский.

## 2. Данные: файл `words.json`

### 2.1. Источник

Репозиторий https://github.com/ittuann/The-Oxford-5000-Word-Lists. В TXT-файлах там только слова без уровней, поэтому уровни CEFR и части речи берутся из PDF:

- `The_Oxford_3000_by_CEFR_level.pdf`: A1, A2, B1, B2;
- `The_Oxford_5000_by_CEFR_level.pdf`: B2, C1;
- `scripts/english-word-frequency.csv`: частотность слов (для сортировки).

В оригинальных списках **нет уровня C2**. Решение: слова C1 сортируются по частотности, более частая половина остаётся C1, более редкая становится C2.

### 2.2. Итоговая структура

Файл лежит в `app/src/main/assets/words.json`. Это массив объектов:

```json
{"id":101,"en":"last","hint":"final","pos":"det.","stage":"A1","level":6,"pg":"det","ru":"последний"}
```

| Поле | Смысл |
|---|---|
| `id` | уникальный номер 1…5321; задаёт глобальный порядок «от лёгкого к сложному» |
| `en` | английское слово или фраза (`have to`, `a, an`) |
| `hint` | уточнение значения из Oxford для многозначных слов (`not heavy`, `river`); часто пустая строка |
| `pos` | часть речи как в Oxford (`n.`, `v.`, `adj., adv.`, `modal v.` …) |
| `stage` | этап: `A1`, `A2`, `B1`, `B2`, `C1`, `C2` |
| `level` | номер уровня внутри этапа, начиная с 1 (по 20 слов) |
| `pg` | группа части речи для подбора неправильных вариантов: `n`, `v`, `adj`, `adv`, `prep`, `conj`, `pron`, `det`, `num`, `exclam`, `other` |
| `ru` | русский перевод, коротко, 1–2 значения через «;» |

Одно и то же английское слово может встречаться несколько раз с разными частями речи и на разных этапах (например, `light` adj. A2 и `light` v. B1). Это разные записи, так и задумано.

Статистика: A1 900 слов (45 уровней), A2 872 (44), B1 807 (41), B2 1427 (72), C1 657 (33), C2 658 (33). Всего 268 уровней.

### 2.3. Как файл собирается

Готовый `words.json` уже лежит в репозитории. Пересобирать его нужно, только если хочешь что-то изменить.

1. `pip install pdfplumber`
2. Склонировать репозиторий со словами.
3. `python tools/build_words.py <папка_репозитория_слов> - out.json`. Скрипт создаст `words_en.json` и `list.txt` (строки вида `id слово (уточнение) часть_речи`).
4. Перевести `list.txt` нейросетью кусками по 500–800 строк с промптом:
   > Переведи английские слова на русский для приложения-тренажёра. Формат ответа строго `id|перевод`, по одной строке на слово. Перевод короткий (до ~25 символов), 1–2 самых частых значения через «; », той же части речи, что указана. Если есть уточнение в скобках, переводи именно это значение. Для служебных слов давай пояснение, например «определённый артикль».
5. Сохранить ответы в `tools/tr/*.txt`.
6. `python tools/build_words.py <папка_репозитория_слов> tools/tr app/src/main/assets/words.json`.

Алгоритм скрипта: PDF читаются по 4 колонкам (границы x = 160 / 292 / 422 pt). Строки `A1`…`C1` в колонке — это заголовки уровней. Строка вида «слово часть_речи» становится записью, перенесённые строки склеиваются. Цифры после слова (`can1`) отбрасываются, текст в скобках уходит в `hint`. Дубликаты (слово + hint + pos) удаляются, C1 делится на C1/C2. Внутри этапа слова сортируются по убыванию частотности и нарезаются по 20 в уровень.

## 3. Экраны и навигация

```
Главный экран
 ├─ Обучение → Этапы (A1…C2) → Уровни этапа (сетка) → Предпросмотр уровня → Вопросы → Результат
 └─ Марафон  → Выбор этапов / Продолжить / Сбросить → Вопросы → Результат
```

Кнопка «Назад» (системная и стрелка в шапке) везде возвращает на предыдущий экран. Во время вопросов в Обучении она сначала спрашивает: «Выйти из уровня? Прогресс этого прохождения будет потерян». В Марафоне выход без вопроса, потому что прогресс сохраняется после каждого ответа.

### 3.1. Шапка (TopAppBar)

- Слева стрелка «Назад» (кроме главного экрана), по центру или слева заголовок.
- **Справа переключатель темы**: иконка солнца (`Icons.Filled.LightMode`) в светлой теме и луны (`Icons.Filled.DarkMode`) в тёмной. Нажатие переключает тему. Выбор сохраняется в DataStore и переживает перезапуск.
- На экране вопросов переключатель **скрыт**, чтобы нельзя было сменить режим посреди прохождения. В шапке там показывается прогресс.

### 3.2. Главный экран

- Название «Oxford 5000».
- Подзаголовок: «Светлый режим» или «Тёмный режим: смешанные вопросы».
- Две большие кнопки-карточки: «Обучение» (с подписью «Пройдено уровней: X из 268» для текущего режима) и «Марафон» (с подписью «Продолжить: вопрос N из M», если есть сохранённый прогресс, иначе «Все слова выбранных этапов подряд»).

### 3.3. Этапы

Список из 6 карточек: A1, A2, B1, B2, C1, C2. На каждой: название этапа, число слов, «Пройдено уровней X из Y» и полоса прогресса. Все этапы открыты сразу.

### 3.4. Уровни этапа

- Сетка плиток (5 в ряд) с номерами уровней 1…N.
- Плитка **зелёная**, если уровень пройден в текущем режиме темы, и **серая**, если нет.
- Все уровни доступны сразу, любой можно пройти или перепройти.
- Нажатие на плитку открывает предпросмотр уровня.

### 3.5. Предпросмотр уровня

- Заголовок «A1 · Уровень 6», отметка «✓ Пройден», если уровень пройден.
- Список из 20 слов этого уровня: английское слово крупно, справа часть речи серым, под ним уточнение (`hint`) курсивом, если оно есть, и перевод. У каждого слова кнопка 🔊.
- Внизу две кнопки: **«Назад»** (к сетке уровней) и **«Начать»** (к вопросам).

### 3.6. Экран вопроса (общий для обоих режимов)

- Шапка: в Обучении «Вопрос 7 / 25» (знаменатель растёт, когда добавляются вопросы) и три сердечка: потерянные ошибки закрашены серым. В Марафоне «Вопрос 15 / 807» или «Работа над ошибками · круг 2 · 3 / 12».
- Тонкая полоса прогресса.
- Карточка с заданием:
  - направление EN→RU: английское слово крупно, рядом часть речи (`adj.`), ниже `hint` курсивом, кнопка 🔊;
  - направление RU→EN: русский перевод крупно, рядом часть речи по-русски (сущ., гл., прил., нар., предл., союз, мест., опред., числ., межд.).
- Под карточкой 4 кнопки-варианта на всю ширину.
- **Реакция на ответ:**
  - **правильно:** выбранная кнопка становится зелёной, через 700 мс автоматически следующий вопрос;
  - **неправильно:** выбранная кнопка красная, правильная зелёная. Вопрос остаётся на экране, пока пользователь не нажмёт появившуюся снизу кнопку **«Дальше»**. В направлении RU→EN при ошибке под карточкой показывается правильное английское слово с кнопкой 🔊.
  - После ответа все варианты заблокированы, повторно нажать нельзя.

### 3.7. Результат

- Обучение, уровень пройден: «Уровень пройден! 🎉», число ошибок, кнопки «Следующий уровень» (открывает предпросмотр следующего уровня; после последнего уровня этапа — первый уровень следующего этапа; после C2 кнопки нет), «Пройти ещё раз», «К уровням».
- Обучение, не пройден: «Уровень не пройден», список слов, в которых были ошибки (слово — перевод), кнопки «Ещё раз» и «К уровням».
- Марафон завершён: «Марафон завершён! 🏁», сколько слов пройдено и сколько ошибок было в первом круге, кнопки «Начать заново» и «На главную». После завершения сохранённый прогресс марафона удаляется.

## 4. Светлый и тёмный режим

Переключатель темы меняет и оформление, и **правила вопросов**:

| | Светлый режим | Тёмный режим |
|---|---|---|
| Цвета | `lightColorScheme` | `darkColorScheme` |
| Направление вопросов | всегда EN→RU: слово на английском, варианты на русском | **смешанное**: в одном прохождении вопросы EN→RU и RU→EN чередуются в случайном порядке |
| Прогресс уровней | свой набор пройденных уровней | **отдельный** набор: в тёмном режиме уровни проходятся заново |
| Прогресс марафона | свой сохранённый марафон | **отдельный** сохранённый марафон |

Как смешиваются направления в тёмном режиме. Для 25 основных вопросов уровня создаётся список направлений: половина EN→RU, половина RU→EN (13 и 12, какое направление получит 13, решает случайность), и он перемешивается. Так в одном раунде гарантированно будет несколько смен направления. Для дополнительных вопросов (+5/+10) и для всех вопросов марафона направление выбирается случайно 50/50 для каждого вопроса.

## 5. Режим «Обучение»: точные правила

### 5.1. Состав прохождения уровня

Пусть выбран уровень `L` этапа `S`, его слова — `W` (обычно 20).

1. **Пул повторения** `P` — все слова всех уровней, которые стоят **раньше** текущего в глобальном порядке: все уровни предыдущих этапов и уровни `1…L-1` текущего этапа. То есть все слова с `id` меньше минимального `id` текущего уровня.
2. **Основные вопросы**: 20 слов уровня и 5 случайных слов из `P`, итого 25. Все 25 перемешиваются вместе.
3. Если в `P` меньше 5 слов (это бывает только на самом первом уровне A1, где `P` пуст), недостающие повторные слова берутся из самого текущего уровня. Значит, некоторые слова будут спрошены дважды. Так и задумано.

### 5.2. Ошибки и дополнительные вопросы

Считается **общее число ошибок за прохождение**, включая ошибки в дополнительных вопросах.

| Ошибок | Что происходит |
|---|---|
| 1-я ошибка | в конец очереди добавляются **5** дополнительных вопросов |
| 2-я ошибка | в конец очереди добавляются ещё **5** (всего дополнительных 10) |
| 3-я ошибка | уровень **сразу не пройден**, прохождение прекращается, показывается экран «не пройден» |

Итого максимум 25 + 10 = **35 вопросов**.

Уровень **пройден**, если пользователь ответил на все вопросы очереди и сделал не больше 2 ошибок. Тогда уровень помечается зелёным в текущем режиме темы и сохраняется.

**Дополнительные вопросы** — это случайные слова из пула `P`. По возможности берутся слова, которые ещё не спрашивались в этом прохождении. Если таких не хватает, допускаются повторы из `P`. Если `P` пуст, слова берутся из текущего уровня.

### 5.3. Варианты ответа

- Всегда **4 варианта**: 1 правильный и 3 неправильных. Порядок вариантов перемешивается при каждом показе вопроса.
- Неправильные варианты подбираются из других слов так:
  1. тот же этап и та же группа части речи (`pg`);
  2. если таких меньше 3 — та же `pg` в любом этапе;
  3. если всё ещё меньше 3 — любые слова.
- Нельзя брать слово, у которого **текст на стороне вариантов** совпадает с правильным ответом (без учёта регистра). Для EN→RU сравнивается `ru`, для RU→EN — `en`. Три варианта также не должны совпадать между собой.
- В RU→EN варианты — это английские слова (`en`) без части речи.

### 5.4. Слова всегда в разнобой

При каждом новом прохождении уровня порядок вопросов перемешивается заново, повторные и дополнительные слова выбираются заново, варианты подбираются и перемешиваются заново. Состав 20 слов уровня при этом неизменен.

## 6. Режим «Марафон»: точные правила

### 6.1. Экран марафона

- Если в текущем режиме темы есть сохранённый незавершённый марафон, показываются:
  - карточка «Продолжить» с этапами марафона и позицией («Круг 1 · вопрос 154 из 1772»);
  - кнопка **«Сбросить прогресс»**: диалог подтверждения, потом удаление сохранения.
- Если сохранения нет: шесть чипов-флажков A1…C2 (множественный выбор, рядом число слов) и кнопка «Начать», активная, когда выбран хотя бы один этап.

### 6.2. Ход марафона

1. При старте все слова выбранных этапов перемешиваются один раз. Получившийся порядок `order` (список `id`) **сохраняется**, чтобы «Продолжить» шло по тому же порядку.
2. **Круг 1**: вопросы идут по `order`. Каждое неправильно отвеченное слово добавляется в список `wrong`.
3. Когда круг закончился:
   - если `wrong` пуст, марафон завершён;
   - иначе начинается **«Работа над ошибками»**: `order = wrong` в перемешанном виде, `wrong` очищается, номер круга +1, вопросы идут заново.
4. Круги работы над ошибками повторяются, пока не будет круга без ошибок.
5. После **каждого** ответа состояние сохраняется в DataStore: этапы, `order`, позиция, `wrong`, номер круга, число ошибок первого круга. Ответ засчитывается и сохраняется в момент нажатия варианта, ещё до кнопки «Дальше».
6. Варианты ответа подбираются по правилам 5.3 и перемешиваются при каждом показе. В тёмном режиме направление каждого вопроса случайное.
7. Дополнительных вопросов и лимита ошибок в марафоне нет.

## 7. Хранение (DataStore Preferences)

| Ключ | Тип | Содержимое |
|---|---|---|
| `dark_mode` | Boolean | включена ли тёмная тема (по умолчанию false) |
| `passed_light` | Set&lt;String&gt; | пройденные уровни в светлом режиме, элементы вида `"A1:6"` |
| `passed_dark` | Set&lt;String&gt; | то же для тёмного режима |
| `marathon_light` | String | JSON сохранённого марафона (или ключа нет) |
| `marathon_dark` | String | то же для тёмного режима |

JSON марафона (kotlinx.serialization):

```kotlin
@Serializable
data class MarathonState(
    val stages: List<String>,
    val order: List<Int>,      // id слов текущего круга
    val pos: Int,              // индекс текущего вопроса в order
    val wrong: List<Int>,      // ошибки текущего круга
    val round: Int,            // 1 = основной круг, 2+ = работа над ошибками
    val total: Int,            // сколько слов было в первом круге
    val firstRoundErrors: Int,
)
```

Важно: подпись APK должна быть **постоянной** (см. 9.3). Иначе каждое обновление придётся ставить через удаление старой версии, и весь прогресс пропадёт.

```
├─ tts/Speaker.kt             — обёртка TextToSpeech (Locale.US), isReady, speak(text)
└─ ui/
   ├─ AppViewModel.kt         — текущий экран, состояние сессии, связь с ProgressStore
   ├─ App.kt                  — тема + переключение экранов + BackHandler
   ├─ theme/Theme.kt          — светлая/тёмная схемы, цвета «правильно/неправильно»
   └─ screens/                — Home, Stages, Levels, Preview, Quiz, Result, Marathon
app/src/test/java/com/oxford5000/learn/logic/LogicTest.kt  — unit-тесты логики
```

Требования к логике (`logic/`):

- Чистый Kotlin без зависимостей от Android, чтобы unit-тесты шли на JVM.
- Случайность только через передаваемый `kotlin.random.Random`, чтобы тесты были воспроизводимыми.
- `LearningSession` хранит: `queue: MutableList<Question>`, `index`, `errors`, `wrongWords`, `status` (IN_PROGRESS / PASSED / FAILED). Метод `answer(optionIndex): Boolean` фиксирует ответ, считает ошибку, при необходимости добавляет +5 или ставит FAILED. Метод `next()` переходит к следующему вопросу или ставит PASSED, если очередь кончилась.
- `MarathonEngine`: `start(stages, words, rnd): MarathonState` и `answer(state, correct, rnd): MarathonState` (возвращает новый state, при окончании круга начинает работу над ошибками), `isFinished(state)`.

Обязательные unit-тесты:

1. В уровне 25 основных вопросов: все 20 слов уровня и 5 из пула.
2. Первый уровень A1: пул пуст, повторы берутся из самого уровня, вопросов 25.
3. 1 ошибка — очередь 30, 2 ошибки — 35, 3 ошибки — FAILED.
4. Ошибка в дополнительном вопросе тоже считается.
5. Пройти все вопросы с 2 ошибками — PASSED.
6. Варианты: всегда 4, правильный ровно один, текстовых дубликатов нет.
7. Тёмный режим: среди 25 основных вопросов есть оба направления (13/12).
8. Марафон: неправильные слова попадают в следующий круг, после круга без ошибок марафон завершён.

## 9. Сборка APK

### 9.1. Через GitHub Actions (основной способ, Android Studio не нужен)

Файл `.github/workflows/build.yml`:

1. Срабатывает на push в `main` и вручную (`workflow_dispatch`).
2. `actions/checkout@v4` → `actions/setup-java@v4` (temurin 17) → `gradle/actions/setup-gradle@v4`.
3. `./gradlew testDebugUnitTest assembleDebug` (на раннерах `ubuntu-latest` Android SDK уже установлен).
4. `actions/upload-artifact@v4` с APK.
5. Публикация GitHub Release `build-<номер>` с прикреплённым `oxford5000.apk` (`softprops/action-gh-release@v2`, `permissions: contents: write`).

Как установить: на телефоне открыть страницу репозитория → **Releases** → последний релиз → скачать `oxford5000.apk` → открыть и разрешить установку из этого источника.

### 9.2. Через Android Studio (запасной способ)

Открыть папку проекта → дождаться синхронизации Gradle → Build → Build App Bundle(s)/APK(s) → Build APK(s). Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### 9.3. Постоянная подпись

В репозиторий кладётся `app/debug.keystore` (alias `androiddebugkey`, пароли `android`). В `app/build.gradle.kts` он подключается к debug-сборке:

```kotlin
signingConfigs {
    getByName("debug") {
        storeFile = file("debug.keystore")
        storePassword = "android"; keyAlias = "androiddebugkey"; keyPassword = "android"
    }
}
```

Это личное учебное приложение, поэтому хранить debug-ключ в репозитории нормально. Зато новые версии ставятся поверх старой, и прогресс сохраняется.

## 10. Порядок работы для ИИ-агента

1. Создать структуру Gradle-проекта (раздел 1), Gradle wrapper 8.10.2, `.gitignore`.
2. Положить `words.json` в `app/src/main/assets/`.
3. Написать `data/`, затем `logic/` и unit-тесты к ней (раздел 8). Добиться зелёных тестов.
4. Написать `ProgressStore`, `Speaker`, `AppViewModel`.
5. Написать экраны в порядке: Home → Stages → Levels → Preview → Quiz → Result → Marathon.
6. Настроить подпись (9.3) и GitHub Actions (9.1).
7. Запушить и дождаться зелёной сборки. Если сборка упала, прочитать лог, исправить и запушить снова.
8. Пройти чек-лист приёмки (раздел 11).

## 11. Чек-лист приёмки

- [ ] Этапов 6 (A1…C2), уровни по 20 слов, у каждого уровня всегда одни и те же слова.
- [ ] Все этапы и уровни открыты, пройденные зелёные, непройденные серые, любой уровень можно перепройти.
- [ ] Перед уровнем показывается список его слов с кнопками «Назад» и «Начать».
- [ ] Уровень: 25 вопросов; 1 ошибка — +5, 2 — +10, 3 — провал; максимум 35.
- [ ] Правильный ответ подсвечивается зелёным с автопереходом; неправильный — красный, правильный зелёный, ожидание кнопки «Дальше».
- [ ] Светлый режим: английское слово и русские варианты. Тёмный: направления перемешаны внутри раунда.
- [ ] Прогресс светлого и тёмного режимов раздельный (и уровни, и марафон).
- [ ] Марафон: выбор этапов, все слова вразнобой, в конце работа над ошибками, «Продолжить» после перезапуска, «Сбросить прогресс».
- [ ] Варианты ответа каждый раз в новом порядке, всегда 4, без дубликатов.
- [ ] Часть речи показана рядом со словом, есть кнопка озвучки.
- [ ] Тема и прогресс сохраняются после закрытия приложения.
- [ ] Новая версия APK ставится поверх старой без потери прогресса.

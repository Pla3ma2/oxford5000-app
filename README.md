# Oxford 5000 — приложение для изучения слов

Android-приложение: 5321 слово Oxford 3000/5000, этапы A1–C2, уровни по 20 слов,
режимы «Обучение» и «Марафон», тёмный режим со смешанными вопросами и отдельным прогрессом.

**Скачать APK:** вкладка [Releases](../../releases) → последняя сборка → `oxford5000.apk`.

- `GUIDE.md` — полное техническое задание и руководство по сборке.
- `app/src/main/assets/words.json` — база слов с переводами.
- `tools/build_words.py` — пересборка базы из PDF Oxford.

Сборка: каждый push в `main` запускает GitHub Actions → тесты → APK → Release.
Локально: открыть папку в Android Studio → Build → Build APK(s).
